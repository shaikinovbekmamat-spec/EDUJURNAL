Повторение

Укажите конец четверти или другой период. Уроки появятся на всех следующих неделях автоматически. Для разового урока снимите галочку.

Какие уроки изменить

Для всех повторений можно изменить предмет, класс, подгруппу, учителя, кабинет и номер урока. Для переноса даты выберите только один урок.

Все часы указаны по времени Кыргызстана. Начавшиеся уроки недоступны для редактирования.
