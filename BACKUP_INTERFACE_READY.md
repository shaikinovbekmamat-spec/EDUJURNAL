# ✅ Готово! Веб-интерфейс для резервного копирования

## Что добавлено

### 1. **BackupService.java** 
Сервис для работы с резервными копиями:
- ✅ Создание резервной копии (pg_dump)
- ✅ Восстановление из резервной копии (pg_restore)
- ✅ Список всех резервных копий
- ✅ Удаление резервных копий
- ✅ Информация о последней копии

### 2. **BackupController.java**
Контроллер с тремя endpoint'ами:
- `GET /backup` - страница управления
- `POST /backup/create` - создать резервную копию
- `POST /backup/restore` - восстановить из копии
- `POST /backup/delete` - удалить копию

### 3. **backup/index.html**
Красивый веб-интерфейс с кнопками:
- 🟢 **Кнопка "Создать резервную копию"** - одним кликом
- 🟡 **Кнопки "Восстановить"** - для каждой копии
- 🔴 **Кнопки "Удалить"** - для каждой копии
- 📊 **Список копий** с датой и размером
- ℹ️ **Инструкции** и предупреждения
- ⚙️ **Настройка автоматического бэкапа**

### 4. **application.yaml**
Добавлены настройки:
```yaml
backup:
  directory: backups
  pg_dump_path: C:/Program Files/PostgreSQL/17/bin/pg_dump.exe
  pg_restore_path: C:/Program Files/PostgreSQL/17/bin/pg_restore.exe
```

## 🎯 Как это работает

### Для Owner:

1. **Войти в систему** → http://localhost:8080/login
   - Логин: `owner`
   - Пароль: `owner123`

2. **На главной странице** нажать кнопку **"💾 Управление резервными копиями"**

3. **На странице бэкапов:**
   - Нажать **"⬇ Создать резервную копию сейчас"**
   - Подождать несколько секунд
   - Увидеть созданную копию в списке

4. **Для восстановления:**
   - Выбрать нужную копию из списка
   - Нажать **"↻ Восстановить"**
   - Подтвердить (будет предупреждение!)

## 🔧 Настройки

Пути к PostgreSQL можно изменить через переменные окружения:
```bash
PG_DUMP_PATH=C:/путь/к/pg_dump.exe
PG_RESTORE_PATH=C:/путь/к/pg_restore.exe
BACKUP_DIR=D:/MyBackups
```

Или в файле `application.yaml`
